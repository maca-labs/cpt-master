# CPT Master

0.5.0では、**追加200問だけの選択・厳密な未見演習・155問180分の学習用通し演習**を追加しました。既存36単元・300問はそのまま維持しています。動画は18本中、確認範囲を限定したおすすめ10本、候補8本です。

日本向け出題範囲との[対応と残る不足](docs/CURRICULUM_GAPS.md)、目標・本文・全問題・動画を追える[詳細対応表](docs/CURRICULUM_v05-300.md)、[教材の照合・レビュー記録](docs/CONTENT_EXPANSION_REVIEW.md)を用意しています。36単元・300問は途中段階であり、最終目標は40〜60小単元・通常600問・別枠の模試専用155問×3セットです。専用問題はまず155問1セットから整備します。いずれも独自の開発目標で、公式の合格条件ではありません。

追加単元のうち6単元に、実プレーヤーの映像・画面内説明を出典と照合した8本を追加しました。日本語NSCA公式6本、英語公式2本です。全編音声・全主張・人間の専門家による確認は未実施です。動画の箇所・目標・出典・再生/埋め込み状態は[0.5動画レビュー記録](docs/VIDEO_REVIEW_0.5.md)、既存候補の保留理由は[従来のレビュー記録](docs/VIDEO_REVIEW_0.3.1.md)を参照してください。

10・20・50問の学習用短縮模試、初見・解き直しを分けた成績分析、復習の優先順位、PWAの更新確認も利用できます。155問の通し演習は既存問題を使う時間配分練習です。専用問題による本番形式模試の審査条件は維持し、引き続き準備中です。検証範囲は[0.5リリース記録](docs/RELEASE_0.5.md)を参照してください。

NSCA-CPTの学習開始位置を見つけ、要点・動画候補・確認問題・復習をつなぐ個人用の非公式学習アプリです。React + TypeScript + Viteで動作し、学習履歴はブラウザーのIndexedDBへ保存します。基本機能にAPIキーは不要です。

GitHub Pagesで **[CPT Master](https://maca-labs.github.io/cpt-master/)** を公開しました。スマートフォンからもこのURLを開いて利用できます。公開先でのPC・モバイル幅の検査、オフライン学習と保存の確認結果はリリース記録にまとめています。PCのローカル版から公開先へ履歴を移すときは、下記のJSONバックアップを使います。

## 起動する

Windowsでは、このフォルダーの **`起動.bat` をダブルクリック**します。Node.jsとnpmが必要です。依存関係が未導入のときだけ`npm ci`を実行し、新しく起動するときはビルド後のプレビューを表示します。

起動先は **[http://127.0.0.1:5173/](http://127.0.0.1:5173/)** です。5173番でCPT Masterが動作中なら、HTMLのタイトルを確認してそのサーバーを開きます。別のアプリが使っている場合は理由を表示し、別ポートへ勝手に切り替えません。

通常の画面確認・基本PWAの確認をターミナルから行う場合：

```powershell
Set-Location -LiteralPath 'C:\Users\shudi\Documents\cpt-master'
npm ci
npm run build
npm run preview -- --port 5173 --strictPort
```

`node_modules`が導入済みなら`npm ci`は不要です。新しく起動したプレビューはターミナルで動作し、`Ctrl+C`で終了できます。既存サーバーを再利用した場合は、新しいサーバーは起動しません。

ソースの編集に追従する**開発用**は`npm run dev`です。既定の接続先は同じ`127.0.0.1:5173`ですが、基本PWAの確認には上記のビルド後プレビューを使います。開発サーバーが動作中なら、先にそのターミナルで終了してください。起動スクリプトは既存のCPT Masterを再利用するため、自動で開発サーバーを置き換えません。

証明書のエラーがあり、Windowsの信頼済み証明書をNode.jsにも使う必要がある環境では、次の方法を使えます。

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\起動.ps1 -UseSystemCA
```

`NODE_USE_SYSTEM_CA=1`はこのスクリプトが起動するnpm子プロセスにだけ設定します。SSL検証は無効化せず、npmのグローバル設定やプロジェクトの外のファイルも変更しません。

## 学習の進め方

1. 「実力診断」で50問に回答します。中断した場合は診断または演習画面から再開できます。
2. 結果の分野別正答率から、優先して学ぶ単元を開きます。
3. 学習目標、動画候補、要点、用語を確認します。動画を見るにはインターネット接続が必要です。
4. 確認問題に回答し、正答だけでなく誤答の理由も読みます。「根拠を説明できる」のチェックは、自分の言葉で説明できる場合だけ付けます。
5. 復習一覧で、期日が来た問題を解き直します。正解しても根拠を説明できなかった問題は復習対象になります。
6. 学んだ内容を短縮模試で確かめ、「成績・弱点分析」から過去の記録と次の単元を確認します。

診断をスキップして先に学ぶこともできます。診断前は診断用50問を通常演習から保留し、完了またはスキップ後に利用できるようにしています。

「厳密な初見」と「解き直し」は別集計です。以前に問題を見た場合や、回答前に解説を見た場合は初見評価に含めません。診断中の解説は終了後にまとめて確認します。同じ問題を再診断しても、新しい初見問題にはなりません。診断は少数の基礎問題による学習目安で、公式換算スコアや合格確率ではありません。

## 追加200問・厳密未見演習

問題演習の「教材の範囲」で「今回追加された200問のみ」を選びます。「厳密な未見問題のみで評価」は、問題・解説の表示履歴と全モードの回答履歴を、問題グループ単位で除外します。10・20・50問から選べます。50問を4回行う場合も、残りの分野別在庫に比例して配分し、中断中の全選出グループを予約して重複を避けます。

不足を既出で補いません。利用可能な件数で始める場合は、そのボタンを明示的に選びます。「通常学習（未見を優先）」と「復習・再演習（既出を含む）」は厳密評価と分けます。結果から誤答・根拠が曖昧だった目標の本文と、その目標に対応する内容確認済み動画へ移動できます。初版50問の診断だけで全300問の習熟は判定しません。

## 通し演習・短縮模試・成績分析・復習

155問・180分の学習用通し演習は、既存300問から重複グループなしで選びます。学習用配分は35・50・48・22問（日本向け整数32・45・43・20の比から最大剰余方式）。全155問を採点し、未回答も分母に含めます。本試験の採点対象140問＋採点外15問とは異なる方式です。

開始前の構成確認と結果に、開始時の未見/既出、模式図/アニメーション/実写、審査状態の件数を表示します。プレビューでは設問を見せません。中断中も時計は進みます。下書き・フラグ・再開・時間切れ採点を保存します。既存問題による時間配分練習であり、本番同等の専用模試や合格可能性の評価とは扱いません。

「短縮模試」で10・20・50問を選びます。既存の学習問題を使う3択・単一正答の練習で、制限時間は学習用の独自設定です。同じ問題グループの重複を避け、採点前は正答と解説を表示しません。問題にフラグを付けて見直し、回答を変更し、保存して再開できます。

- **学習用**：保存して中断すると時計も停止します。
- **時間配分練習**：タブを閉じても時計が進み、期限後に再開すると採点します。

未回答も全出題数の分母に含めます。初回診断前の問題は予約しているため、選択した配分の問題が不足する場合は、問題数を減らすか診断を完了・スキップしてから開始します。155問の本番形式は、専用の問題数・専門家レビュー・画像映像問題などの条件が揃ってから提供します。

「成績・弱点分析」では、厳密な初見と解き直しの正答率、分野別の回答数・問題グループ数、根拠を説明できた割合、回答時間の中央値、学習日別の回答数と時間を確認できます。弱点単元から教材・関連動画へ移動できます。過去比較は完了した学習を形式ごとに行い、短縮模試は同じ出題数と時間方式の記録を比べます。

未学習の正答率は0%にせず、記録なしとして表示します。説明可の割合は自己申告で、少数の問題や既出問題による結果は能力の確定値ではありません。正答率から合否や合格確率を計算しません。

復習は、期限超過・繰り返すつまずき・手動登録を優先し、回答時間を補助情報として順番を調整します。正解して根拠を説明できた場合と、誤答・根拠が曖昧な場合を分けて次の復習予定を更新します。

## 保存とJSONバックアップ

保存先は、**端末・ブラウザー・接続元（スキーム／ホスト／ポート）ごとの保存領域**です。PCの`127.0.0.1:5173`と`localhost:5173`、GitHub Pagesの公開先、スマートフォンでは履歴を共有しません。ローカル版は上記の`127.0.0.1:5173`に統一してください。端末間の自動同期はありません。

1. 移行元の設定画面（[PCローカル版](http://127.0.0.1:5173/#/settings)）で「JSONを書き出す」を押し、ダウンロードしたファイルを確認します。
2. PCで公開版を使う場合も、スマートフォンへ移す場合も、移行先で[公開URL](https://maca-labs.github.io/cpt-master/)を開きます。スマートフォンへは保存したJSONファイルも移し、その設定画面で「JSONを取り込む」から選びます。
3. 事前検査後に、作成日時・件数・マージ方法を確認します。
4. 確認チェックを付け、「復元前バックアップを保存してマージ」を押します。

復元は既存データを残す追加マージです。**同じIDは移行先のローカル記録を優先**します。表示・解説の初回時刻は早い時刻を保持し、診断の完了状態を後戻りさせません。現行教材版`2026-11-04.2`と、互換性を検証した旧版`2026-11-04.1`に対応します。旧版は元の100問・8単元への参照と問題の改訂・選択肢等を検査して移行し、未知の版や不正な参照を拒否します。IndexedDBの構造はversion 1を維持しています。

解答・表示履歴、演習の対象バッチ・未見条件と予約、短縮模試・通し演習の状態、復習、お気に入り、学習時間、視聴記録、メモ、動画の個人設定を含みます。旧0.4の途中の短縮模試・メモ・個人設定も復元できます。ブラウザーのデータを削除する前や、公開先を変更する前に書き出してください。移行後の変更は自動では同期されないため、必要な端末から改めて書き出してマージします。異なる端末の進行中の厳密演習で予約が重複するマージは、既存データを保護して取り消します。

## 動画の個人設定

動画画面でURLの追加・編集・非表示・並べ替えができます。おすすめは内容審査記録・目標・出典が整合する動画に限定します。個人設定の保存に審査済み状態を含めず、同じ配布動画と学習目標を使う場合だけ現行教材の審査を表示時に適用します。必要に応じて「配布設定に戻す」で個人用の変更を解除できます。変更はそのブラウザーの個人設定で、配布教材やGitHubのファイルには反映しません。視聴済みと学習メモも、問題演習による理解度とは分けて保存します。

動画一覧JSONは書き出せます。個人設定を含む復元には、設定画面の学習バックアップを使ってください。動画をダウンロード・再配布する機能はありません。埋め込みで見られない場合はYouTubeで開いて確認します。

## PWAのオフライン準備と更新

オフライン確認は、ビルド後プレビューへオンラインで一度アクセスし、教材の読み込みとサービスワーカーの準備を済ませてから行います。YouTubeの再生はオフライン対象に含みません。初回から通信なしで開けることや、すべての端末でのインストールを保証するものではありません。

1. 通信できる状態で公開版またはビルド後プレビューを開き、「教材のオフライン準備ができました」の案内を確認します。ホーム画面への追加は、ブラウザーに表示される案内から行います。
2. 「オフライン学習・ホーム画面への追加」を開き、「更新を確認する」で新しい版を確認できます。
3. 更新案内が出たら必要な回答・メモを保存し、確認チェックを付けて「更新して再読み込み」を押します。「あとで」を選んだ場合は、後から更新案内を再表示できます。

解答中の画面では更新の適用を保留します。回答を保存して中断し、演習・設定などの画面へ移動してから更新してください。更新の再読み込みと、ブラウザーの保存データ削除は別です。保存済みの履歴は引き続き利用しますが、定期的なJSONバックアップも行ってください。

日本公式Web・日本語ハンドブック・米国版には、配分や版の相違があります。採用値・出典・確認日・未確認事項は[設定画面の出題基準](http://127.0.0.1:5173/#/settings)と[教材レビュー記録](docs/CONTENT_REVIEW.md)を確認してください。OSHAなど米国の資料を、日本の法律上の義務として扱いません。
