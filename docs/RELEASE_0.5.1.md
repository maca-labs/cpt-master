## 動画の追加と確認範囲

新規26本（限定おすすめ14本・候補12本）、総計44本（限定おすすめ24本・候補20本）。元の不足22単元すべてに候補またはおすすめの入口を用意し、そのうち13単元には目標の一部分を照合したおすすめを追加した。全目標・全単元の内容確認が完了したわけではない。

栄養表示、水分の分類、BMIの関係式、家庭血圧の測定条件、割合計算、本人の反応に応じた運動強度、周期の階層、静的と動的ストレッチの区別、関節症の条件と専門職連携、糖尿病の足の確認、漏えい時の被害拡大防止、行動支援、同意説明の基本部分を追加した。日本語を優先し、確認可能な英語の公式動画も補助に用いる。

新規おすすめ14本の方法は、同一動画との対応を確認した公式文字起こし6本、実プレーヤーの主要画面8本。すべてAIの照合で、人間の専門家レビューは0本。字幕・動画本体や外部フレームの保存・転載・再配布は行わない。

メタデータ確認、内容と出典の照合、再生、埋め込みを独立して保存・表示する。全44本のうち再生は18本で一部確認、埋め込みは7本で一部確認。他の状態は未確認のまま。公式文字起こしを読めたことから、映像の正確さや再生成功を推定しない。視聴済みにした候補を自動でおすすめに変えない。

旧版・アーカイブ、患者向け・研究参加者向け、海外の制度・対象年齢の違いを記録し、処方・法律・一般化に使えない範囲を明示した。熱中症動画は安全上重要な文脈を確認し切れず候補に保留。CPR/AED動画は実技講習や認定条件の代替ではない。
