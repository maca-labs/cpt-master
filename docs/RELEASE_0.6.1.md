# 0.6.1 専用模試の公開

「模擬試験」から[専用模試](https://maca-labs.github.io/cpt-master/#/exam/full)を開けます。0.6.0で整備した3セット計465問と83点のオリジナル図・アニメーションを公開しました。設問、解説、出典、問題の改訂番号はローカル審査版と同じです。すべてAIによる出典照合済みで、人間の専門家レビューは未実施です。出題形式に沿った非公式の学習用模試です。

各セットは155問、180分、3択。採点対象140問（面談・評価32、計画45、実技43、安全20）を得点に含め、採点対象外の15問は提出後に区分を表示します。公式の合否や換算スコアは表示しません。中断・再読み込み後も締切時刻は変わらず、回答と見直しフラグが端末に残ります。

通常学習600問、集中模試20問、通常問題を使う通し演習を維持しています。専用模試の受験記録は端末内で通常学習と別に保存し、通常学習のJSONバックアップには含めません。

公開版の各問題に出典箇所・照合記録を、各素材に制作元・利用根拠・SHA-256を保持しています。元の出題範囲・分野別件数と過去の検証記録は[0.6.0教材記録](RELEASE_0.6.md)を参照してください。
