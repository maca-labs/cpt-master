# 0.3.0 実装・公開記録

確認日：2026-11-04（Asia/Tokyo）。教材版 `2026-11-04.1`、動画カタログ版 `2026-11-04.2`。既存の学習履歴を削除する変更はありません。

## 今回の実装

- 10・20・50問の学習用短縮模試。日本向けの整数設定32・45・43・20から最大剰余方式で配分し、3択単一正答、設問順・選択肢順の保存、同一グループの重複防止に対応。
- 模試の下書き自動保存、回答見直し、フラグ、一時停止できる時計／中断中も進む時計、中断再開、制限時間終了時の採点、分野別結果、誤答からの教材・復習への移動。
- 模試の未回答は全出題数の分母に含め、架空の回答履歴を作りません。初回診断前の予約問題は短縮模試にも出さず、不足数を表示します。
- 成績・弱点分析。初見と解き直し、分野別の理解の手がかり、問題グループ数、回答時間中央値、同形式の過去比較、記録に基づく日別学習表・グラフ。空の履歴から成績を作りません。
- 復習の優先順位。期限超過、連続誤答、根拠の説明可否、手動登録、回答時間を使い、期日が来た問題から選びます。合格確率は算出しません。
- PWAのオフライン準備・更新案内、インストール手順、更新の手動確認。新しい版の再読み込みは利用者の確認後に行い、解答中は保留します。
- GitHub Pages用のサブパス・manifest・アイコン・Service Worker設定、検査とビルドを行う公開ワークフロー。
- 短縮模試の復元競合対策。同じセッションIDは移行先のセッションと採点台帳を一組として優先し、トランザクション内の最終検査が失敗した場合は全体をロールバックします。
