## 追加200問を選ぶ学習

- 問題演習で「すべて」「0.4で追加された200問」、10/20/50問を指定できる。バッチ情報は別のカタログに置き、既存問題のデータ本体やIDを変えない。
- 「通常学習（未見を優先）」「厳密な未見問題のみで評価」「復習・再演習（既出を含む）」を区別。
- 厳密未見は、全モードの設問表示・解説表示・解答履歴を問題グループ単位で除外。選出した未表示問題も、中断中は予約する。50問×4回の選出で重複せず、分野配分は残り在庫に比例させる。
- 不足数・未見数・既出数・予約数を表示。不足を既出で自動補充しない。「利用可能なN問で始める」は明示的な選択が必要。
- 選出・予約は、最新の履歴と設定を読み直すIndexedDBトランザクションで行う。古いセッションの再開や結果一覧も、他の厳密演習の予約を表示直前に確認する。
- 本文の表示は履歴の保存完了後。解説先読み等で既出になった回答は、厳密評価と分野別評価の分母から除外し、件数も表示する。
- 誤答・根拠が曖昧だった目標から本文と、その目標に対応する内容照合済み動画へ移動できる。対応動画がなければ不足を明記する。
- 初版診断50問を追加200問・全300問の習熟判定として表示しない。過去比較も対象バッチ・未見条件・問題数を分ける。

## 155問・180分の学習用通し演習

既存300問を使い、セッション内のグループ重複なしで155問を選ぶ。専用の本番形式模試とは別の `mock.format: through` として保存する。

| ------------------------------- | ----------------------------------------------------------- |
| 面談・評価 / 計画 / 技術 / 安全 | 35 / 50 / 48 / 22問                                         |
| 配分の根拠                      | 日本向け整数32/45/43/20を155問へ最大剰余方式で配分          |
| 時間                            | 180分、中断・閉じている間も継続                             |
| 採点                            | 全155問、未回答も分母に含める                               |
| 本試験との差                    | 採点対象140問＋採点外15問の方式や専用の初見模試を再現しない |

開始前に選んだ155問の構成だけを示し、設問は見せない。開始時の未見/既出、模式図/アニメーション/実写、AI照合/人間専門家レビューの件数を表示する。結果でも開始時の在庫と実際に厳密初見で回答できた件数を区別する。媒体・審査状態は現行教材から集計する。

回答下書き・フラグ・現在位置・期限を保存し、再読込・中断後に再開できる。時間切れは一度だけ採点する。公式換算スコア・合格確率・合否は算出しない。初回診断50問と、厳密未見演習の予約問題は除外し、分野別不足を表示する。

専用模試の `pool: exam` と従来の審査条件は維持。専用問題は0問のままで、本番形式は準備中。将来はまず155問1セットを通常学習と別に整備し、その後3セットを目指す。

## 履歴とバックアップの互換性

- IndexedDBはversion 1のまま、既存ストアを削除しない。教材版は `2026-11-04.2`、動画カタログ版は `2026-11-05.1`。
- 追加したセッションの条件は任意項目で、旧0.4の通常演習や10/20/50問短縮模試も復元できる。
- `2026-11-04.1` の100問時代のバックアップも従来の移行検査を維持。
- 既存300問のID・改訂・group・データ本体を、固定した0.4スナップショットのSHA-256と全件比較。
- 合成した旧0.4バックアップで、回答・表示・復習・お気に入り・単元メモ・動画メモ・並べ替え・ダーク設定・途中の20問短縮模試の下書きとフラグを確認。利用者の保存領域を検証用に操作していない。
- JSONは事前検査・利用者確認後に追加マージ。同一IDのローカル優先と、表示時刻の最早記録は維持。不正な形式や、異なる端末の進行中厳密演習で予約が重複する合成状態は全書き込みをロールバックする。
- 学習履歴の自動同期は行わない。端末や公開先を移る場合は設定画面のJSONバックアップを使う。
