## 集中模試

「模擬試験」に特別な対象者・安全管理の集中模試を追加した。オリジナルの3択20問で、計画10問と安全管理10問。制限時間は23分20秒。回答・フラグを保存して中断でき、再開後に全20問を採点する。未回答も分母に含め、採点後に解説・出典・関連単元を確認できる。再挑戦は同じ問題セットを使い、問題順と選択肢順を入れ替える。

設問はAIが出典を照合し、既存の通常問題との重なりと安全上の条件を別のAIレビューでも点検した。通常教材300問と集中模試20問を別の出題枠で管理する。専用155問の本番形式は、専門家レビューなどの公開条件を満たす問題がそろうまで準備中。

教材版は `2026-11-08.1`。既存バックアップ `2026-11-04.1` と `2026-11-04.2` は、問題と選択肢への参照を検査して読み込める。集中模試の保存・採点は既存のIndexedDBを使う。複数タブでは保存済みの回答と時計の変更を反映し、採点済みの回答を重複登録しない。
