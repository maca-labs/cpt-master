# 0.6.0 教材記録

この版は通常教材40単元・600問（診断50問を含む）です。既存300問、集中模試20問と動画52本の記録を保持しています。「教材の範囲」から第3版を優先した追加300問だけを選べます。出題と評価の方法には厳密な未見評価、未見優先、解き直しがあります。既出の判定は従来どおり問題グループと表示・解説の履歴を参照します。

## 専用模試と公開条件

専用模試は既存の通し演習・集中模試と分離して管理します。各セット155問・180分。採点対象は分野順に32／45／43／20、採点対象外の自作15問は3／5／5／2。採点対象外の内訳はアプリ独自です。採点対象外は総得点・分野別得点の計算に使いません。解答は端末内の別データベースでセット単位に保存します。

3セットの分野別件数は各35／50／48／22問です。セット01は既存の専用問題、セット02・03は今回作成した計310問です。配信済みの問題を差し替えたり、診断・通常演習・集中模試を専用セットへ流用したりしていません。

| セット | 設問 | 静止図 | アニメーション | 専門家レビュー済み |
| ------ | ---: | -----: | -------------: | -----------------: |
| 01     |  155 |     25 |              4 |                  0 |
| 02     |  155 |     28 |              0 |                  0 |
| 03     |  155 |     26 |              0 |                  0 |

図版はこの教材用のSVGです。制作元、制作経緯、利用範囲、確認日、ファイルのSHA-256をセット別の台帳に保存しました。設問・素材の構造検査では、設問ID、問題グループ、正規化した問題文、図版ハッシュの再利用を点検しました。文面の類似候補は判断の違いも確認し、検出結果は専門家審査の参考に残します。
専用問題と素材はローカル審査領域に置き、通常ビルドとGitHub Pages用ビルドから除外します。人間の専門家レビュー前の公開用画面は「準備中」です。審査では、個別の設問・解説・図版が同じ判断を導くこと、各セットの難易度や領域の偏り、教材からの独立性を確認してください。

- 通常版：`npm run dev` → [ローカルアプリ](http://127.0.0.1:5173/)
- ローカル審査版：`npx vite --config authoring/dedicated-mock/vite.config.ts` → [セット選択](http://127.0.0.1:5181/)
