## 履歴・バックアップの互換性

IndexedDBはschema version 1を維持し、既存レコードを消去・再作成しない。拡充前に保存した100問のSHA-256が全件一致するテストを用意した。教材総数が増えるため進捗率の分母は変わるが、過去の解答数や正誤は変更しない。

旧版`2026-11-04.1`の実コードから書き出したテスト用バックアップを、事前検査・確認を経て現行版へ復元できる。旧100問/8単元に限定した参照、改訂、選択肢、セッション所属と問題別キー、同一セッションの重複回答を検査する。未知の版、不正な参照・改訂・履歴を拒否する。既存データを残すマージと合成後検査をトランザクション内で行い、失敗時は戻す。

単元メモ、視聴メモ、視聴済み、動画の個人設定、お気に入り、復習、テーマ、診断状態、解答/表示履歴を移行・再読込して確認した。これは隔離されたテストDB/ブラウザーでの確認であり、利用者の実データをテスト用記録へ置き換えてはいない。端末間の自動同期は範囲外。
