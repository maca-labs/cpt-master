# 0.4.0 教材拡充の照合・レビュー記録

確認日2026-11-04（Asia/Tokyo）。通常学習300問（診断50問を含む）、300問題グループ、本文36単元。既存8単元・100問へ、28単元・200問を追加した。未収録範囲は[出題範囲との対応表](CURRICULUM_GAPS.md)に明記する。

## 確認の種類

| 種類                 | 実施内容                                                                                                                           | 状態の意味                                                                                                               |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 作成担当AIの出典照合 | 公開一次資料の記載を実読し、設問条件、正答、各誤答理由、本文を小バッチごとに照合。計算は再計算し、資料の地域・年代・対象条件を記録 | 300問が`source_checked`。元100問は[従来の記録](CONTENT_REVIEW.md)を維持、新200問は各`review`へ方法・日時・改訂番号を保存 |
| 別担当AIのレビュー   | 追加200問と対応本文を読み、単一正答・意味の重複・本文不足・誤答の妥当性を点検。一次資料の再照合範囲は以下の分野別記録に区別        | 人間の専門家レビューや、全資料の全面的な監査とは異なる                                                                   |
| 自動検査             | 型、参照、選択肢、件数、重複候補、審査宣言、採点・保存・復元等を検査                                                               | 合格しても内容の正確性を自動承認せず、審査状態を変更しない                                                               |
| 人間の専門家レビュー | 今回は未実施                                                                                                                       | `expert_reviewed`は0問。本番形式模試へ転用しない                                                                         |

全問題を一括生成して事後に件数だけ整えたものではない。評価は10/10/10/10/6問、計画は8問ずつ8回、技術は8問ずつ7回と6問、安全は8/7/7/6問のバッチで、本文・設問・出典照合を行って収録した。日時はビルド時に現在時刻を付ける方式にせず、実際の確認記録を静的保存する。

## 独立AIレビューの範囲

- [評価・栄養46問](ASSESSMENT_AI_REVIEW.md)：全問の条件・正答・誤答と本文を該当一次資料に再照合。32問の誤答を改善し、該当する新問だけ改訂2とした。
- [計画64問](PLANNING_AI_REVIEW.md)：対象・再照合資料・数値の検算・近接判断の扱いは個別記録を参照。
- [技術62問](TECHNIQUE_AI_REVIEW.md)：全問の文章と本文を点検し、34問は全根拠を再照合、1問は一部の根拠のみ再照合、27問は構成点検。原著者側の出典照合記録とは分ける。
- [安全・職務28問](SAFETY_AI_REVIEW.md)：全問を6一次資料の該当節に再照合。窒息の目標・本文、資料名・版・頁、病歴取得時の同意の説明を補った。

同じ判断の単なる言換えを独立グループとして数えないよう、既存100問と追加分を比較した。技術036は既存の準備運動問題から心理的準備とテンポの分類へ、052は049の吸収動作から減速局面の姿勢移行へ、054は計画の反応課題から腕とバランスの役割へ差し替えた。同じ目標の共有まで排除するわけではなく、300群を300種類の心理測定上独立した能力と解釈しない。

計算・条件付きの判断を追加し、極端な断定だけで消去できる誤答を改善した。ただし基礎問題や易しい誤答も残る。項目の難度・識別力・信頼性を実受験者のデータで検証したわけではなく、公式試験と同等の難度や合格可能性を示すものではない。

## 既存データと残る課題

元100問の全オブジェクトのSHA-256を拡充前に保存し、一致をテストする。IndexedDBスキーマv1を変えず、旧版の実コードが書き出したテスト用JSONを復元・再書出し・再読込して照合する。利用者のDBをテストデータに置き換える処理は行わない。セッション外参照・余分なキー・重複回答等の不正な復元は書込み前に拒否し、マージ後の不整合もトランザクションで戻す。

登録動画10本の確認状態は今回変更していない。おすすめ2本は確認範囲が限定され、候補8本のうち6本は字幕の疑義等で保留、2本は本編未確認。新28単元の直接対応動画は不足している。[動画の詳細記録](VIDEO_REVIEW_0.3.1.md)を参照。動画の視聴を救命実技講習や資格認定の代わりにしない。

専用の模試問題・専門家審査・実写素材の権利/内容確認は未完了。通常300問の重複で155問模試や3セットを作らない。実行した検証と公開結果は[0.4.0リリース記録](RELEASE_0.4.md)へ記載する。
